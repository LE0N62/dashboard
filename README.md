# Proyecto: Dashboard Analítico con Gráficas Personalizadas, Interpretación y Consultas

## Estructura del Proyecto
- `index.html`: Interfaz principal del dashboard interactivo.
- `css/styles.css`: Estilos responsivos con soporte para tema claro y oscuro.
- `js/data.js`: Dataset estructurado del caso práctico (*NovaTech Retail México*, 144 transacciones).
- `js/charts.js`: Módulo de gráficas personalizadas con Chart.js (cambio de paletas, tipos de gráfico y exportación PNG).
- `js/sql_engine.js`: Motor de consultas SQL ejecutado localmente en el navegador sobre la tabla `ventas`.
- `js/app.js`: Controlador de filtros dinámicos, KPIs, interpretación automática y paginación.
- `data/ventas_novatech.csv`: Archivo CSV con los datos crudos del caso práctico.
- `docs/caso_practico.md`: Documento de planteamiento e interpretación ejecutiva de resultados.

## Cómo ejecutar
1. Descomprime el archivo `proyecto_dashboard_consultas.zip`.
2. Abre `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox). No requiere instalación ni servidor backend.
